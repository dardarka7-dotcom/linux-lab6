## Назначение файлов
* `health_check.sh` — скрипт проверки состояния сервера (сеть, нагрузка CPU/RAM/Disk, топ-5 процессов, статус служб `ssh` и `cron`, список пользователей с `UID >= 1000` и членов группы `sudo`).
* `create_users.sh` — скрипт массового создания учётных записей и групп отделов из CSV-файла с генерацией временного пароля и требованием его смены при первом входе.
* `employees.csv` — входной CSV-файл со списком новых сотрудников.
* `log_analyze.sh` — скрипт анализа журнала аутентификации (подсчёт успешных и неудачных попыток входа, поиск IP-адресов с `>= 3` неудачными попытками для блокировки, выявление попыток запуска `sudo` без прав).
* `crontab.txt` — конфигурация планировщика `cron` (автоматический запуск `health_check.sh` каждые 5 минут).
